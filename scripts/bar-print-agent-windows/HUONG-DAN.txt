TN COMPANY - BAR PRINT AGENT CHO WINDOWS
========================================

May pha che khong can cai Node.js, npm hay mo trinh duyet.

Yeu cau:
- Windows 10/11 64-bit.
- May Windows va may in KV838/BP-T3 cung mang LAN.
- May in co IP co dinh va mo cong RAW 9100.
- May Windows co Internet de ket noi API TN Company.

Cai dat:
1. Giai nen toan bo file ZIP.
2. Bam dup CAI-DAT.cmd va chon Yes khi Windows hoi quyen Administrator.
3. Nhap IP may in, dia chi API va tai khoan POS theo huong dan.
4. Chon Y de in phieu test.

Cap nhat ban moi:
- Neu da cai agent truoc do, bo cai tu dong giu nguyen toan bo cau hinh cu.
- Chi can giai nen ZIP moi va chay lai CAI-DAT.cmd, khong can nhap lai thong tin.

Sau khi cai:
- Agent chay an ngay lap tuc.
- Agent tu chay khi Windows khoi dong, khong can dang nhap.
- Agent tu chay lai sau 15 giay neu mang/API chua san sang hoac gap loi.
- Khi dang nhap Windows, Task Scheduler cung kich hoat lai agent de du phong.
- Phieu in ho tro day du tieng Viet co dau (ten mon, ghi chu, nhan vien).
- Khong dong/xoa thu muc C:\ProgramData\TNCompany\BarPrintAgent.

Xem log:
C:\ProgramData\TNCompany\BarPrintAgent\logs\bar-print-agent.log

Go cai dat:
Bam dup GO-CAI-DAT.cmd va chon Yes.
